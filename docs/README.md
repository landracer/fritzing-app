# Documentation index

This is the living documentation for the `landracer/fritzing-app` fork-of-record. If you are an
agent or new contributor, read the repo-root [`../AGENTS.md`](../AGENTS.md) first — it is the entry
point and onboarding contract.

## Layout

- **`../AGENTS.md`** — onboarding + working conventions (read first).
- **`panelizer.md`** — user-facing guide to the panelizer feature.
- **`design/`** — design-time references and specs (panelizer-v2, gerbview port reference).
- **`internal/`** — newest-first internal progress logs (append a dated entry at the end of each
  working session; keep newest at the top).

## Conventions for docs here

- **User-facing** docs describe *what the feature does and how to use it*. **`design/`** and
  **`internal/`** are engineering references — not shown to end users.
- Keep `internal/` logs **newest-first** and dated, so a new session can read the top and know the
  current state immediately.
- When you add a feature, add/refresh a `design/` reference and link it from `../AGENTS.md` §2 and
  the README table.
