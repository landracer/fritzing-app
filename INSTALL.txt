# Building / installing Fritzing (this fork)

This fork is built on **Qt 6** (tested against Qt 6.11.x). The build no longer pins an old Qt point
release, so any current Qt 6 works. You build it from source; there is no prebuilt package here.

## Prerequisites

A recent Linux (glibc ≥ 2.6), or a recent macOS / Windows 10+ install, plus the Qt 6 dev packages
and the native deps the app links against:

* Qt 6: `qtbase` (Core/Gui/Widgets/Xml/Sql + sqlite driver), `qtsvg` (Svg/SvgWidgets),
  `qtserialport`, `qt5compat` (Core5Compat), `qttools` (lrelease/lconvert at build time)
* QuaZip built for Qt 6
* Boost (headers)
* libgit2
* OpenSSL 3
* ngspice (shared library, used for circuit simulation)
* svgpp (header-only SVG parser)

On a Fedora/RHEL-style box:

```sh
sudo dnf install qt6-qtbase-devel qt6-qtsvg-devel qt6-qtserialport-devel \\
                 qt6-qt5compat-devel qt6-qttools-devel quazip-qt6-devel \\
                 boost-devel libgit2-devel openssl-devel ngspice-devel
```

On Debian/Ubuntu-style boxes, install the Qt 6 equivalents (qt6-base-dev, qt6-svg-dev,
qt6-serialport-dev, qt6-5compat-dev, libquazip-qt6-dev, libboost-dev, libgit2-dev, libngspice0,
…).

The part library is a **separate repository** checked out into `parts/`:
[https://github.com/fritzing/fritzing-parts](https://github.com/fritzing/fritzing-parts).

## Build

Out-of-tree is recommended:

```sh
mkdir build && cd build
qmake6 ../phoenix.pro
make -j"$(nproc)"
```

This produces a `Fritzing` binary in the build directory. Run it from there:

```sh
./Fritzing
```

On Linux, if the app cannot find `libngspice.so` at runtime, make sure the ngspice shared library is
installed (it is searched for in the usual system library directories such as `/usr/lib64` and
`/usr/lib`, in addition to Qt application library paths).

## Notes on macOS

Recent macOS versions block "unverified" software by default. After launching, open
System Settings → Privacy & Security and click "Open" on the Fritzing prompt, or set the system to
allow downloads from identified developers.
